## Integration notes

- Exported objects follow the `*_stylized` naming convention.
- Resource variants are intended to feed PrefabRegistry / world-builder variant selection.
- Creature meshes are static art bases and still need gameplay rigging/animation polish.
- Landmark meshes are intended as hero world props and can be split into sub-prefabs later if needed.
- This script prioritizes strong readable silhouettes and painterly realism over exact high-poly realism.
