# Unity package ownership

- Registry packages should normally use an explicit package version.
- Git packages must use an immutable release SHA or tag; production dependencies must not track a floating branch such as `main`.
- Embedded packages are reserved for intentional local forks or patches. Such a package must document why it is embedded and how it differs from upstream.
- `Packages/packages-lock.json` is generated by Unity Package Manager and must describe the same dependency model as `Packages/manifest.json`.
- The project currently has no intentional embedded MCP or Cinemachine package. MCP is resolved from the pinned Coplay release revision and Cinemachine from the Unity registry at version `3.1.2`.
